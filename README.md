# Asu Singh — Portfolio

An interactive, backend-centric portfolio built with Next.js App Router, React, TypeScript, Tailwind CSS, Framer Motion, and react-three-fiber.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production builds

```bash
npm run build:next
```

The standard Next.js build is used by Vercel. `npm run build` also produces the Sites-compatible build for the included hosting workflow.

## Deploy to Vercel

Import the repository into Vercel and deploy. The included `vercel.json` selects the standard Next.js build.

No environment variables are required. The contact form opens the visitor’s email client.
